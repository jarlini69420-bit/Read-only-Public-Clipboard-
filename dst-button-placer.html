How to use
  1. Upload an uncropped screenshot with your HUD showing (or use the blank screen).
  2. Pick a button, then drag it, use the arrow keys (Shift for 10 px), the arrow pad, or type exact numbers.
  3. Use Zoom for fine adjustments; scroll the preview when zoomed in.
  4. Copy each script and paste it in the console with the toggle on Local.
