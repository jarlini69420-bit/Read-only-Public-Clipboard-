Copy MW_Dn first; then Copy MW_Go() becomes available. In game, switch the console to Local mode and run MW_Dn([[ID]]). Wait for the download OK message (if it says download failed, check the ID and try again), then, still in Local mode, paste and run the Copy MW_Go + run command. It applies the macro, runs it and clears the console history. Your previous macro is saved as mw_macro_bak. Typing MW_Go() instead only applies it.
